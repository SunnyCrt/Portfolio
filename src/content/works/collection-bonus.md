## 기획 배경 및 목적

소환수 도감은 소환수 성장 및 수집을 위한 시스템으로, 동일한 소환수를 반복 획득하면 해당 소환수의 도감 단계가 상승합니다.

또한 도감 단계마다 소환수에게 필요한 추가 능력치를 제공하는 도감 효과가 있으며, 도감 단계가 상승하면 도감 효과 역시 상승하여, 이를 통해 소환수를 성장시킬 수 있습니다.

기존 도감에 속성별로 공유하는 보너스 도감 포인트를 추가하여, 특정 소환수를 획득하지 않아도 소환수의 도감 단계를 상승시킬 수 있도록 기획했습니다.

보너스 도감 포인트는 속성별 5성 소환수 획득 횟수에 따른 속성별 소환수 도감의 단계에 따라 지급되며, 동일한 속성의 5성 소환수에게 사용할 수 있습니다.

#### 기획 의도 및 방향성

- 사용한 포인트를 회수·재사용할 수 있도록 하여 편의성 제공하고 소환수 육성 과정의 부담 완화
- 높은 단계의 도감 효과 이용의 허들을 낮춰 소환수 육성 동기 부여
- 기존 도감 시스템을 유지하면서 보너스 포인트에 의한 추가 성장을 함께 제공

## 핵심 시스템 구조

#### 포인트 획득
- 속성별 소환수 도감의 도감 단계 총합이 상승하면 해당 속성의 보너스 도감 포인트를 획득

특정 속성 소환수 획득을 해당 속성 소환수 도감의 성장과 연결하여, 여러 소환수의 획득이 특정 속성 전체에서 사용할 수 있는 성장 자원 획득으로 이어지도록 구성했습니다.

#### 포인트 사용
- 획득한 포인트를 동일 속성 5성 소환수의 도감에 사용 시 도감 단계 및 도감 효과 상승

포인트를 사용하면 해당 소환수의 도감 포인트가 증가하며, 사용한 보너스 포인트와 증가하는 도감 포인트는 1:1 비율로 적용되도록 설계했습니다.

또한 소환수 획득을 통해 기존에 누적한 도감 성장과 보너스 포인트를 이용한 추가 성장을 함께 반영하되, UI에서 보너스 포인트 적용 여부를 확인할 수 있도록 구성했습니다.

#### 포인트 초기화 및 재분배
- 특정 소환수 도감에 사용한 포인트를 회수하여 다른 소환수의 도감에 다시 사용할 수 있도록 구성

회수한 포인트는 다시 해당 속성의 가용 포인트로 돌아가고, 동일 속성의 다른 소환수에게 재사용할 수 있도록 구성했습니다. 유연한 사용 구조를 통해 소환수 육성 과정의 피로도를 완화하고자 했습니다.

#### 예외 처리
- 도감 단계 총합이 최고 단계를 달성하더라도 내부적으로는 도감 단계 달성에 사용되는 카운트를 계속 누적

라이브 서비스의 특성상 추후에 속성별 소환수 도감의 최대 단계가 확장될 수 있음을 고려하여, 도감 최대 단계를 확장했을 때 기존 플레이 기록이 반영될 수 있도록 구성했습니다.

## 데이터 및 UI

### 데이터 설계
- 보너스 도감 포인트의 획득·사용·초기화 규칙을 데이터로 관리할 수 있도록 신규 데이터 구조 설계
    - 속성, 적용 대상, 초기화 비용, UI 리소스 등 시스템 운영에 필요한 항목을 데이터에서 관리할 수 있도록 구성
- 기존 도감 관련 데이터에 보너스 포인트 적용 여부 등 필요한 설정값 추가

| 데이터 컬럼명 | 타입 | 설명 |
| :--- | :--- | :--- |
| attribute | enum | 포인트 속성 설정 |
| target_rank | int | 포인트를 사용할 소환수의 등급 설정 |
| reset_cost | key_value | 포인트 초기화에 필요한 재화 및 비용 설정 |
| icon_image | string | 포인트 아이콘 이미지 설정 |
| name_string | string | 포인트 이름 입력 |
| desc_string | string | 포인트 설명 입력 |

※ 위의 표는 데이터 구조 설계 설명을 위해 재구성한 예시입니다.
