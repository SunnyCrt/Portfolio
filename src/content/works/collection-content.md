## 기획 배경 및 목적

게임 내에 소환수 및 형상변환 일러스트, 소환사 의상 일러스트, 지역 및 콘텐츠 BGM 등 다양한 아트·사운드 리소스가 존재하지만 이를 감상할 수 있는 공간이 없어, 플레이 과정에서 획득하거나 경험한 리소스를 수집하고 다시 감상할 수 있는 **회상의 서재**를 기획했습니다.

일러스트와 BGM을 단순히 열람하는 기능에 그치지 않고, 항목별 수집 조건과 카테고리별 수집 진행도를 부여하여 기존의 플레이 경험이 수집으로 이어지도록 구성했습니다.

또한 수집 진행도에 따라 단계적인 보상을 제공하여 수집에 대한 동기를 함께 제공하고자 했습니다.

#### 기획 의도 및 방향성

- 게임 내 일러스트와 BGM을 다시 감상할 수 있는 공간 제공
- 소환수 육성, 형상변환·의상 수집, 지역 및 콘텐츠 플레이 등의 경험을 수집 조건과 연결
- 서로 다른 리소스의 특성에 맞춰 카테고리 및 해금 조건을 구분
- 수집 진행도와 단계별 보상을 통해 지속적인 수집 동기 제공

## 핵심 콘텐츠 구성

- 수집 항목은 **소환수 일러스트** / **형상변환 일러스트** / **소환사 일러스트** / **BGM**의 4개 카테고리로 구성
- 각 카테고리는 기존 게임 콘텐츠의 특성에 맞는 별도의 수집 조건과 분류 기준을 적용

#### 소환수 일러스트
- 5성 소환수를 대상으로 일러스트 제공
- 불 / 물 / 바람 / 빛 / 어둠 속성별로 구분
- 소환수 5각성 시 해당 소환수의 일러스트를 수집 처리
- 단, 일러스트 감상은 일러스트 수집 여부와 관계없이 가능

제공되는 소환수 일러스트 속 소환수의 모습이 소환수 5각성 시 변화하는 모습인 점을 고려하여, 소환수 5각성을 수집 조건으로 설정함으로써 소환수 육성 경험이 회상의 서재에 반영될 수 있도록 설계했습니다.

#### 형상변환 일러스트
- 형상변환이 존재하는 소환수를 대상으로 일러스트 제공
- 불 / 물 / 바람 / 빛 / 어둠 속성별로 구분
- 형상변환 획득 시 해당 형상변환의 일러스트를 수집 처리
- 단, 일러스트 감상은 일러스트 수집 여부와 관계없이 가능

형상변환 획득 자체를 수집 조건으로 설정하여, 형상변환에 대한 플레이어의 소유욕을 자극할 수 있도록 설계했습니다.

#### 소환사 일러스트
- BM 판매 의상에 해당하는 일러스트를 대상으로 제공
- 소환사 클래스별로 구분
- 헤어, 머리 장식, 의상, 의상 장식을 모두 획득하여 의상 세트를 완성하면 해당 의상 세트의 일러스트를 수집 처리
- 단, 일러스트 감상은 일러스트 수집 여부와 관계없이 가능

단일 아이템이 아닌 의상 세트 전체 획득을 수집 조건으로 설정하여, BM 의상에 대한 플레이어의 소유욕을 자극할 수 있도록 설계했습니다.

#### BGM
- 마을·필드·지역 던전에서 사용되는 **지역 BGM**과 아레나·레이드·전장·길드 등에서 사용되는 **콘텐츠 BGM**로 구분
- 퀘스트 완료, 대륙 오픈, 특정 맵 입장 등 실제 플레이 경험을 조건으로 수집 처리
- 일러스트와 달리 수집한 BGM만 감상 가능
- BGM 재생 시 관련 로딩 일러스트를 배경으로 함께 노출

BGM의 경우 각 BGM이 사용된 지역이나 콘텐츠를 파악하여, 특정 지역 또는 콘텐츠의 해금을 수집 조건으로 설정했습니다.

#### 수집 및 보상
- 수집 항목은 수집 조건을 충족하면 자동으로 수집 처리
- 누적된 수집 수량에 따라 단계적으로 보상 제공

보상은 여러 단계로 구성하여 수집의 체감 난도를 완화하였고, 마지막 단계 보상은 명예 보상(칭호)으로 설정하여 회상의 서재에서 획득한 보상이 게임의 밸런스를 해치지 않도록 설계했습니다.

## 데이터 및 UI

### 데이터 설계
- 기존의 소환수 / 형상변환 / 의상 관련 데이터에 회상의 서재 사용 여부 및 일러스트 리소스 설정값 추가
- BGM 컬렉션 관리를 위한 신규 데이터 구조 설계
- 카테고리별 수집 단계 및 보상 관리를 위한 신규 데이터 구조 설계
- 수집 종류, BGM 종류 등 콘텐츠 구분을 위한 enum 추가

소환수·형상변환·의상 정보는 기존 데이터를 활용하되 회상의 서재에 필요한 설정값을 추가하고, 기존 구조로 관리하기 어려운 BGM과 수집 보상은 별도 데이터로 분리하여 관리할 수 있도록 설계했습니다.

| 데이터 컬럼명 | 타입 | 설명 |
| :--- | :--- | :--- |
| collection_type | enum | 수집 콘텐츠 타입(카테고리) 설정 |
| reward_step | int | 수집 단계 설정 |
| need_value | int | 수집 단계 달성에 필요한 누적 수집 수량 |
| reward_key | int | 수집 단계 달성 시 지급할 보상 설정 |

※ 위의 표는 데이터 구조 설계 설명을 위해 재구성한 예시입니다.

### UI 설계

#### 회상의 서재 메인 화면
![회상의 서재 메인](/works-images/collection-content/archive-main.png "인게임에서 실제로 구현된 회상의 서재 메인 화면"){width=720}

- 각 수집 콘텐츠를 시각적으로 구분하여 원하는 카테고리에 바로 접근
- 수령 가능한 수집 보상이 있는 카테고리에 레드닷 표시
- 각 카테고리 내부에서도 수령 가능한 보상 버튼에 레드닷 표시

#### 일러스트 수집
![일러스트 수집](/works-images/collection-content/archive-illust.png "인게임에서 실제로 구현된 소환수 일러스트 화면"){width=720}
- 속성 또는 소환사별로 수집 항목 구분
- 현재 수집 수량과 다음 보상까지 필요한 수량을 게이지와 카운트로 표시
- 다음 단계에서 받을 수 있는 보상 아이템을 함께 노출
- 수집 조건을 충족한 경우 보상 받기 버튼 활성화
- 수집 여부에 따라 썸네일 상태를 구분하되, 미수집 상태에서도 일러스트 감상 가능

#### 수집 보상 처리
![수집 보상](/works-images/collection-content/archive-reward.png "기획서 상의 단계별 수집 보상 UI 예시"){width=420}
- 목표 수량 미달성 : 보상 버튼 비활성화
- 목표 수량 달성 : 보상 버튼 활성화
- 보상 수령 : 다음 단계의 진행도로 변경
- 마지막 단계 완료 : MAX 표시 및 수령 완료 상태로 변경
